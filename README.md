# gemma-void-filter
Гибридное промежуточное ПО (middleware) для стабилизации латентных пространств моделей класса Gemma на опорной частоте 80.08 Гц. Реализует каскадную фильтрацию контекста через NumPy и обучаемый PyTorch Gate-адаптер. Предотвращает Context Drift и Prompt Injection через адаптивный перцентильный клиппинг.
